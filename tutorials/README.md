# Tutorials

Tutorials are maintained educational material for current neurOS and ORION workflows.

A tutorial should:

- use the current config/runtime/plugin architecture,
- explain inputs, outputs, and evidence limitations,
- avoid depending on undocumented local state,
- be updated when stable APIs change,
- link exploratory variants to `experiments/` instead of embedding large research branches in the learning path.

Legacy notebooks should be validated before promotion into this directory.
