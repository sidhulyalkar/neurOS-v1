# Changelog

All notable user-facing changes to neurOS and ORION should be recorded here. This file is intentionally concise; detailed scientific/evidence boundaries belong in the referenced documentation and pull requests.

The project follows the compatibility and release rules in `docs/RELEASE_POLICY.md`.

## Unreleased

### Added

- fail-closed hardware qualification manifests bound to verified runtime qualification bundles;
- invariant SNAP-derived spectral representation evidence with pinned upstream conformance;
- optional ngc-learn 3.2.x RateCell interoperability with explicit JAX/upstream identity and deterministic evidence hashes;
- public scientific-claim, governance, support, security, citation, and release policies;
- release-candidate artifact validation and checksum generation.

### Changed

- ecosystem compatibility is increasingly expressed as executable evidence rather than package-name support claims;
- NeuroAI integrations remain isolated from the runtime kernel and are promoted one evidence rung at a time.

### Claim boundary

These changes do not by themselves establish clinical validation, biological correctness, safety certification, real-device qualification for unnamed hardware, or closed-loop qualification.

## Historical releases

Historical implementation details remain recoverable from Git tags, commits, and merged pull requests. This changelog begins as a maintained public contract from the current release train onward rather than reconstructing unverified release notes retroactively.
