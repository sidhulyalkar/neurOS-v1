The software-contract portion of this roadmap is implemented by v1.0 in PR #14:

- frozen artifact schema catalog;
- manifest v2 → v3 migration;

- deterministic scientific fingerprint separated from execution run hash;

That program should advance only when corresponding artifact fingerprints exist.
