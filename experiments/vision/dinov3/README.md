# DINOv3 Neuroscience Experiments

This directory preserves the repository's DINOv3-based neuroscience exploration, including cell-tracking, atlas, compression, alignment, and multi-dataset notebooks plus associated paper drafts.

These files were moved from `notebooks/` and `docs/` without rewriting their research content. They are intentionally classified as **experiments**, not as supported neurOS runtime examples.

## How to interpret this work

- Results may depend on historical dependency versions or external datasets.
- Individual notebooks may be exploratory rather than reproducible end-to-end on current CI.
- Performance numbers in historical notebooks/papers are not current neurOS runtime qualification claims.
- Reusable methods should be promoted behind a stable package/interface only after tests and controlled evaluation justify that move.

The stable runtime and ORION architecture should remain independent of DINOv3-specific implementations.
