# Supported Examples

Files under `examples/` are intended to be maintained user-facing workflows, not scratch research.

Promotion here requires:

- current neurOS/ORION APIs,
- deterministic configuration where practical,
- a CI smoke test,
- no hidden hardware/cloud requirement unless clearly named,
- documented inputs and expected outputs,
- no unsupported performance or clinical claims.

Exploratory work belongs under `experiments/` until it satisfies those gates.
